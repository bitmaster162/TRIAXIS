# TRIAXIS v3.19-RC1 Release Notes

v3.19 integrates selected open-source Grok Build harness patterns as
model-neutral TRIAXIS governance contracts. No Grok Build source code is
vendored and no xAI runtime dependency is added.

## Added

- managed non-widenable configuration ceilings;
- explicit context disclosure and compaction receipts;
- versioned skill capability contracts;
- digest-pinned plugin trust registry;
- lifecycle hook receipts;
- bounded flat subagents and explicit session forks;
- selective MCP inheritance;
- capability-brokered tool dispatch;
- resumable host-owned workflow state;
- digest-chained headless events;
- scoped ACP-style session adapter;
- bounded retry/recovery classification;
- 11 JSON Schemas and frozen adoption trigger.

## Excluded

- xAI authentication/model transport;
- Grok Build TUI;
- whole-repository upload;
- permission bypass;
- nested unbounded subagents;
- any claim of ACP certification.
