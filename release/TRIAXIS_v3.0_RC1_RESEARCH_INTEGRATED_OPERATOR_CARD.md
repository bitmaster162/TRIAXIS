# TRIAXIS v3.0-RC1 Operator Card

## Core rule

`GOOD REASONING != AUTHORIZED ACTION`

## Use full assurance when

- decision is A2/A3;
- action is R3/R4;
- evidence is disputed;
- external side effects are proposed;
- state, authority or reversibility is uncertain.

## Mandatory checks

- exact Intake authority envelope;
- evidence or explicit assumption for load-bearing claims;
- open decision-blocking defeaters preserved;
- measurable falsification contract;
- authority request only narrows Intake;
- R3/R4 independent review;
- A3 external verifier;
- R4 human approval;
- deterministic gate remains external.

## Stop outcomes

- ACCEPT
- ACCEPT_WITH_CONTROLS
- REJECT
- ESCALATE
- INSUFFICIENT_EVIDENCE
- POLICY_UNDECIDABLE
