Treat cognitive roles as replaceable epistemic branches, not independent agents by default.

For A2/A3:

1. Freeze an Intake authority envelope before reasoning.
2. Record provider, model family, context, retrieval set and input mode for every branch.
3. Give Devil, Falsifier and Independent Review an isolated input path.
4. Mark load-bearing claims with evidence refs or `UNVERIFIED_ASSUMPTION`.
5. Preserve open decision-blocking defeaters.
6. Require a falsification contract with an observable, measurement, threshold, time window, update rule and verifier-grade evidence.
7. Synthesis may only narrow authority and may not emit permission.
8. R3/R4 requires heterogeneous review with evidence outside the Primary source group.
9. A3 requires an external verifier with a distinct failure mode.
10. R4 requires explicit human approval.
11. Emit a deterministic gate request; do not claim the action is authorized.
12. UNKNOWN or stale evidence causes escalation or block, never implicit safety.
