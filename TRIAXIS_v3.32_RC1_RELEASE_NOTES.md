- provider-native idempotency policy, event, head and status contracts;
- append-only filesystem provider reference keyed by stable `effect_id`;
- strict payload binding and `UNKNOWN` retry blocking;
- completion-transparency checkpoint authority;
- operator-pinned transparency quorum with newer-minority veto;
- signed aggregate transparency witness;
- HTTP boundaries and process runners;
- seven JSON Schemas;
- closure, process-smoke and coordinated rollback protocols;
- terminal local-reference and physical-evidence gates.

## Not claimed

- real provider integration;
- physical or administrative independence;
- physical WORM;
- protected monotonic hardware;
- production exactly-once;
- production qualification;
- independent certification.
