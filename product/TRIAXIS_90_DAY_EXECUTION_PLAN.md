# TRIAXIS 90-Day Execution Plan

## Days 1–14 — internal proof

- audit one existing internal agent in read-only mode;
- create 30 seeded failures across evidence, authority, state and replay;
- compare MVT versus full TRIAXIS;
- measure latency, tokens and human review;
- remove roles that do not add measurable value.

Exit: one reproducible internal case and honest benchmark report.

## Days 15–30 — service pilot

- package AI-Agent Reliability Audit;
- recruit 3–5 pilot teams;
- audit one workflow per team;
- collect defect acceptance, remediation completion and willingness to pay.

Exit: at least three completed external audits or evidence that the offer must change.

## Days 31–60 — Research Assurance MVP

- upload 2–5 reports;
- claim/evidence extraction;
- source correlation;
- contradiction and unsupported-number register;
- human adjudication screen;
- downloadable Decision Assurance Receipt.

Exit: one external user completes a real decision with the MVP.

## Days 61–90 — controlled runtime integration

- GitHub PR approval adapter without auto-merge;
- email draft approval without auto-send;
- CI FAIL-BENCH gate;
- signed policy and action envelopes through an external key service prototype.

Exit: one tool workflow with complete mediation in a safe/non-destructive environment.
