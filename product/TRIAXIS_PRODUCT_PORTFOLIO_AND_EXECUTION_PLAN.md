# TRIAXIS Product Portfolio and Execution Plan

## Positioning

Do not sell “seven AI personalities”. Sell **Decision Assurance and Action Authorization**.

## Product ladder

1. AI-Agent Reliability Audit — fastest revenue and failure corpus.
2. Research Assurance — easiest repeatable software MVP.
3. Decision Assurance Engine — reusable typed case compiler.
4. TRIAXIS-FAIL-BENCH — public proof and vendor evaluation.
5. Execution Firewall — enterprise runtime control.
6. Decision Assurance Receipt protocol — interoperability and ecosystem.

## Build order

### Now

- run the audit service on one internal agent;
- adjudicate the three TRIAXIS reports as Case 002;
- collect real timings, false positives and human decisions;
- ship local JSON/Markdown report generator.

### Next

- connectors for GitHub PR, email draft and read-only database query;
- web UI for claims/evidence/defeaters;
- CI release gate;
- policy pack for code change and outbound messaging.

### Later

- managed identity integration;
- cloud gateway adapters;
- on-prem enterprise control plane;
- public benchmark and model-role leaderboard.

## Moat

The moat is not prompts. It must become:

- proprietary real failure corpus;
- calibrated evaluators;
- policy/action adapters;
- decision-to-execution provenance;
- domain policy packs;
- independent benchmark credibility.
