# Decision Closure / EBD Research

This research track separates three objects:

1. **Decision Closure Protocol** — sufficiency, minimal witness, flip boundary, discriminator, and stop.
2. **Decision Closure Benchmark** — method-neutral evaluator for those closure dimensions.
3. **Decision Trace / Auditability** — provenance and replayability layer motivated by Boundary-20.
4. **Trialectic Closure** — conditional REALITY → ANGEL → DEVIL → CLOSURE implementation; not default persona debate.

## Current empirical state

- Z8.1: Ordinary and Structured both reached ceiling on action accuracy.
- EBD v0.2 Pilot40: Ordinary and Structured both 40/40 actions; no action lift.
- Boundary-20: both 20/20 actions; after symmetric oracle quarantine, evidence binding was Ordinary 14/16 vs Structured 16/16 (+12.5 pp), with zero action harm.
- GPT-5.6 Sol self-test on Decision Closure-24: U0 Ordinary, U1 Decision Closure and U2 Trialectic Closure all passed the full closure vector, but this is **author-contaminated sanity control only**, not blind evidence.

## Research rule

Do not claim that TRIAXIS improves model intelligence or final-answer accuracy from current evidence.

Test narrower falsifiable hypotheses:

- sufficiency detection;
- minimal sufficient witness construction;
- counterfactual / flip-boundary precision;
- cost-aware discriminator selection;
- decision-frontier stopping;
- provenance / traceability / auditability.
