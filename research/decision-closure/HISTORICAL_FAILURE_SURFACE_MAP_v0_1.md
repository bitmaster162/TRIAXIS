## Historical pressure

The most severe collapses were **pre-reasoning boundary failures**:

- malformed input;
- semantic ingress;
- action routing;
- context-role scope;
- graph ordering.

A second recurring class was **evidence/state integrity**:

- correlated evidence treated as independent;
- stale or misbound authority state;
- checkpoint/subject/scope binding;
- later external-verifier and authorization provenance.

This is evidence against the simplistic hypothesis that the main missing ingredient was simply more Devil/Angel debate. It points toward the same direction now represented by EBRC/WMX:

`context acquisition -> evidence provenance -> compact state -> bounded commitment -> discriminator/verifier -> correction -> stop`

The historical pattern is a research prior only. External replay decides whether it produces actual lift.
