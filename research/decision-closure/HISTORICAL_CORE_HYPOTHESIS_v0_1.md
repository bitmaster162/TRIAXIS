# Historical Core Hypothesis v0.1

## Question

Did the useful core of TRIAXIS already exist before the later assurance/runtime expansion?

Current answer: **probably yes, but not in one historical release**.

The surviving candidate is a recombination of mechanisms that appeared at different points:

1. `v2.3` — evidence lock + bounded Devil/Angel/Falsifier + stop.
2. `v2.5` — evidence-origin/common-cause independence.
3. `v2.8-v2.10` — input contract + semantic ingress + role/context scope + graph invariance.
4. `v3.0` — role labels demoted; defeaters + measurable falsification + external verifier.
5. `EBRC` — explicit separation of epistemic resolution from operational closure.
6. `WMX` — compact state + selective external verifier + bounded correction + zero-VOI stop.

The v2.34-v3.32 runtime/security line is useful engineering for its own failure surfaces,
but it is not currently part of the candidate cognitive core.

## Candidate minimal core

```text
INPUT / CONTEXT BOUNDARY
          ↓
EVIDENCE + ORIGIN
          ↓
DUAL STATE
(epistemic ≠ commitment)
          ↓
BOUNDED COMMITMENT
          ↓
OPTIONAL COUNTERMODEL
          ↓
DISCRIMINATOR / VERIFIER
          ↓
REOPEN OR STOP
```

## Historical interpretation

The original TRIAXIS insight was not simply `DEVIL + ANGEL`.

The more durable pattern appears to be:

- bind reality before reasoning;
- do not count correlated repetition as independent support;
- distinguish task-control text from quoted/external data;
- preserve a concrete defeater rather than synthesize it away;
- convert disagreement into an observable test;
- commit to a bounded action without requiring metaphysical certainty;
- reopen only on material evidence;
- stop when no affordable evidence can change the commitment.

## What is explicitly outside the cognitive core

Until external evidence says otherwise:

- default persona theatre;
- majority vote;
- repeated debate rounds;
- proprietary identity/authorization stacks;
- checkpoint/trust/runtime machinery unrelated to the target decision;
- full v3.32 assurance stack as a general reasoning prompt.

## Falsifier

This hypothesis fails if a simpler arm — Direct, Self-Critique, or Proposer/Verifier —
matches the candidate core across external benchmarks at lower cost.
