# TRIAXIS R5 — CAPABILITY UPGRADER

## Objective
R5 turns a frontier model into a measured capability portfolio:

`probe -> detect weakness -> classify -> select donor -> execute -> verify -> promote/reject -> remember`

It does not imitate model branding. It borrows only testable mechanisms.

## Minimal-first architecture
1. **Base probe** — freeze raw model output/artifact.
2. **Gap detector** — classify F1..F9.
3. **Capability router** — select the smallest plausible donor mechanism.
4. **Combination ladder** — minimal verifier -> one donor -> two donors -> parallel composition.
5. **Verification gate** — correctness, constraints, regressions, and material cost.
6. **Capability memory** — store `failure fingerprint -> donor -> discriminator -> verified effect -> contraindications`.
7. **Frontier target registry** — refresh current external target before each campaign.

## Donor families
- **OpenAI / GPT-5.6**: deep reasoning, tool/terminal execution, parallel workstreams.
- **Anthropic / Fable 5**: long-horizon autonomous execution, self-testing, multi-stage repository work.
- **Google / Gemini**: multimodal reasoning, MCP/document grounding, reusable skills, fast tool loops.

If an external model is unavailable, R5 records `MECHANISM_EMULATION`, never `MODEL_USED`.

## Frozen experiment ladder
`B0 BASE`
`B1 MINIMAL VERIFIER`
`B2 SINGLE TARGETED DONOR`
`B3 TWO-DONOR COMPOSITION`
`B4 FULL CAPABILITY ROUTER`

B1-B4 receive the same maximum correction count. Exact compute is measured rather than assumed equal.

## Primary current gap
Repo-scale software engineering / behavioral reconstruction.

OpenAI's current GPT-5.6 release table reports Sol at 64.6% on SWE-Bench Pro versus 80.0% for Claude Fable 5 and 80.3% for Claude Mythos 5. This is a concrete capability gap despite Sol leading other coding evaluations.

## R4 consequence
R4 found Minimal Proposer+Verifier == Full TRIAXIS on a non-ceiling 2400-point task. Therefore R5 starts minimal-first. EBRC remains controller/audit state unless it demonstrates incremental task lift.

## Promotion
A capability is promoted only when the weakness was measured before donor activation, the donor was selected by a preregistered failure fingerprint, the result beats B1 on verified task outcome, regression/cost vetoes pass, and the result repeats on the targeted surface.

## Collapse
If B4 repeatedly equals B1/B2/B3, collapse the cognitive core to:

`capability detector -> minimal router -> verifier -> bounded correction -> gate -> memory`

That is a successful research result.

## External-model boundary
Actual top-model synergy requires real independent calls to GPT/Claude/Gemini on frozen tasks. Public documentation may seed donor hypotheses, but cannot be relabeled as an external model run.
