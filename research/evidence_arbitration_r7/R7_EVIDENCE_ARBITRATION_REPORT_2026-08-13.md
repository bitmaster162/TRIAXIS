## 2. Highest-confidence cross-report consensus

- Broad "self-evolving agent" novelty is not defensible.
- Failure-driven skill/context improvement has direct prior art.
- Skills can be null or harmful; usage is not utility.
- Complex routers and larger ensembles do not automatically beat simple baselines.
- Held-out / prospective transfer is mandatory to distinguish evolution from overfit.
- B4/full TRIAXIS has no privileged scientific status.
- Independent/executable verification should dominate self-judgment when an exact oracle exists.
- Null and harmful mechanisms must be reversible, stale-able, demotable and deletable.

## 3. Claim adjudication

### C1 — failure-conditioned capability upgrading

**R7: PRIOR ART ESTABLISHED; no novelty claim.**

Retain as an engineering rule only. SkillOpt and EvoSkill already turn execution failures into targeted updates under validation gates.

### C2 — heterogeneous donor portfolio

**R7: LIKELY COMBINATION OF PRIOR ART; possible integration wedge only.**

MCE and EvoSkill already evolve heterogeneous context/code/tool-like assets, while routing systems select models. TRIAXIS may differ in enforcing one common evidence/admission protocol across models, tools, docs, search, verifiers and compute, but this exact distinction is unproven.

### C3 — incremental donor attribution

**R7: methodologically strong, not a novelty claim.**

B1→B2→B3→B4 remains the correct causal experiment structure. Do not market ablation/credit attribution as an invention.

### C4 — complexity deletion

**R7: broad pruning/deletion is known prior art; narrow component-level causal-null deletion remains unresolved.**

Skill/context pruning is established. TRIAXIS's narrower rule—an entire router/architecture component loses activation eligibility after repeated matched nulls—should remain a research subclaim until broader systems/governance prior art is searched.

### C5 — EBRC non-cognitive controller

**R7: strongest surviving research wedge; novelty still unproven.**

SkillHone already supplies role-separated evaluation and persistent decision history. EvoSkills/CoEvoSkills already separate generation and verification. TRIAXIS's candidate difference is the combined control surface:

`evidence provenance + instrument validity + contamination + epistemic state + operational closure + reopen/stop + budget + stale/demotion + rollback`

This should be investigated as a governance/control-plane contribution, not credited for cognitive lift.

## 5. vNext architecture accepted after correction

The second GPT report is the strongest architecture draft of the six.

```text
TASK + ENVIRONMENT + AUTHORITY
        ↓
GPT-5.6 Sol
        ↓
observable probe / failure fingerprint
        ↓
deterministic admissibility + harm gate
        ↓
sparse registry lookup
        ↓
ABSTAIN or ONE targeted intervention
        ↓
independent / executable verifier
        ↓
≤1 verifier-conditioned correction
        ↓
fresh verification
        ↓
immutable receipt
```

Default arm:

`B1 = minimal proposer/base + smallest valid verifier + ≤1 bounded correction + deterministic gate`

B2 is conditional research. B3 is experimental. B4 is assembled only from components that individually passed causal gates.

## 7. What imports now

Controller-only imports:

- hard optimizer/evaluator isolation;
- append-only evidence journal;
- materialized active registry;
- exact provider preflight;
- model/harness/benchmark epoch freeze;
- strict held-out admission;
- negative/harm memory;

- stale/regressed/rejected lifecycle;
- executable/formal verifier precedence;

These receive **no cognitive-lift credit**.

## 10. Current scientific position

The strongest positive hypothesis is no longer "TRIAXIS is a self-evolving intelligence architecture."

It is:

> **A sparse capability-augmentation system in which every donor and every layer is a contestant, while a separate evidence-control plane prevents contaminated, stale, harmful or causally uncredited changes from becoming active capability memory.**

Even this is a research hypothesis, not a novelty or efficacy claim.
